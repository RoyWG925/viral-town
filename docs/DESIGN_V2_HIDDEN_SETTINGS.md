# VIRAL 設計 v2：隱藏的設定，越玩越懂

> 草案，2026-10-17。依據你給的三張投影片（慶典準備度八量表、角色卡第二版、人際關係），對照目前引擎與 P1–P11 的實測資料整理。
> 原則：**設定要多、要具體，玩家才有東西可以「推」；但不直接攤開，而是用世界裡的線索暗示，並在每次遊玩後一點一點解鎖。**

---

## 0. 為什麼現在需要這一層

P5–P10 的資料顯示，目前玩家能「推」的東西太模糊：

- 角色的差異主要在「能做的動作」，但**沒有人有具體的想要、害怕、價碼**。所以同一句話給不同人，只是換一條傳到警察或記者的路。
- 故事沒有共同的「賭注」。燈籠節在 38/38 局都「照常」，玩家不知道自己在對什麼施壓。
- 玩家看到結局後，很難推論「下次換一句話、換一個人，會不會不一樣」。

你的三張投影片剛好補上這三個缺口：

- 角色卡讓每個人有槓桿點。
- 人際關係讓一句話同時碰到好幾條線。
- 慶典量表讓每個故事都有共同的賭注。

---

## 1. 三層設定怎麼接進引擎（誠實原則不變）

| 層 | 誰擁有 | 誰看得到 | 怎麼改變 |
|---|---|---|---|
| **慶典準備度（八量表）** | 引擎（確定性規則） | 玩家看不到數字；世界裡看得到徵兆 | 只有**已驗證的事件**能讓量表變動 |
| **角色卡 v2** | 作者撰寫的資料 | Gemma 只看到**自己那張**；玩家靠觀察解鎖 | 不會變；是角色的「本性」 |
| **人際關係 v2** | 作者撰寫的資料 + 引擎更新的數值 | Gemma 只看到**自己對別人**的關係；玩家靠觀察解鎖 | 已驗證的事件跨過門檻時，數值才會變 |

Gemma 仍然只決定「這個人怎麼理解、相信、感受、行動」，引擎仍然擁有真相、知識和可能性。新增的設定只是讓每個人的判斷**有更具體的依據**，也讓引擎有更多「後果」可以計算。

## 2. 慶典準備度：八量表（採用，稍作調整）

八個量表（0–100）都由引擎根據**已驗證事件**計算，不呼叫模型。

| 類 | 量表 | 起始 | 會讓它掉的「已驗證事件」（現有或小幅新增） | 世界裡的徵兆（不顯示數字） |
|---|---|---|---|---|
| 人 | 主辦與人手 | 70 | 志明被追究、表演學童被家長留在家（新：美咲扣住女兒） | 舞台邊的工人變少、志明來回奔走 |
| 物 | 物資 | 75 | 美玲關店／扣住鴿籠（新）、阿德關店（點心） | 鴿籠空了、攤位少了點心 |
| 錢 | 經費 | 50（已超支） | 超支被揭穿（文章、聲明）、阿德討債（新） | 布告欄出現「經費調整」公告 |
| 地 | 場地安全 | 60（支架鬆動） | 舞台封鎖；**安全疑慮被親眼證實**才會掉 | 封鎖線、警察站崗 |
| 名 | 市長的支持 | 70 | 市長被迫澄清、被拍到、被揭穿 | 市長在台階上焦慮踱步 |
| 心 | 民意 | 65 | 爆料、攤商聚集、謠言傳遍全鎮 | 路人交頭接耳、對鎮公所比手畫腳 |
| 眾 | 出席意願 | 70 | 警察出動（害怕）、安全謠言傳遍、攤商罷市 | 廣場人潮變稀、有人提早回家 |
| 時 | 準備進度 | 60 | 志明被打斷、吵架、彩排被封鎖 | 舞台燈還沒亮、倒數時鐘變紅 |

**20:00 的結局由量表決定**（新的確定性規則）：

- 全部 ≥ 門檻：🏮 **燈籠節照常舉行**（但會有「縮水」細節，例如沒有鴿子、沒有點心）。
- 任一量表跌破門檻：⚠️ **縮水舉行**、**延後**或**停辦**，看是哪一個量表、掉多少。
- 市長若用 `cancel_festival`（Gemma 的決定），一樣直接取消。

這讓每個故事都有共同的賭注，玩家的動機自然會出現：「我能讓燈籠節辦不成嗎？」「我能救它嗎？」

**玩家看得到什麼**：

- 遊玩中：不顯示量表，只有世界徵兆。
- 結算時：小報最後一段寫成「今晚的燈籠節：沒有鴿子、少了點心，延後半小時開場」，**用文字，不用數字**。
- 多玩幾次後：「鎮民筆記」會解鎖「燈籠節需要的八樣東西」，但只列出已經看過跌破的那幾項。

## 3. 角色卡 v2：寫名詞，不寫形容詞（8 位，草稿）

格式依照你的投影片。**秘密**各有兩個：一個關於自己（沿用現有秘密，維持目前故事），一個關於別人（新增，用來製造三角關係）。
新增的「關於別人」的秘密，要先加進 FACTS，並設定洩漏偵測關鍵字，才能維持「不知道就不能說」的規則。

### 阿德（麵包店）
- **擁有**：慶典全部的點心（燈籠酥）、鎮上最熱鬧的店面
- **專屬**：店裡客人會把他說的話帶出去（規則：他在店裡說的話，會以「聽客人說」的方式傳給 1–2 位熟客）
- **今晚想要**：在開場時被市長公開感謝
- **怕**：被當成笑話
- **秘密（自己）**：烤箱檢查過期兩個月 *(現有)*
- **秘密（別人）**：市長去年的慶典點心錢還沒付 *(新事實)*
- **偏誤**：什麼事都覺得是衝著他來
- **傳話**：數字一定加倍；從不直接跟美玲說心事
- **底線**：不會讓慶典沒有點心
- **價碼**：被市長公開羞辱，就揭露欠款
- **台詞**：「我跟你說，這事我只跟你講。」「哎唷，這下慘了啦！」

### 美玲（花店）
- **擁有**：全部的花飾、鴿籠的鑰匙
- **專屬**：能讓鴿子不上場（扣住鴿籠）
- **今晚想要**：放鴿子前確定牠們不會受驚
- **怕**：動物受傷
- **秘密（自己）**：收了志明的錢佈置鴿籠，私下覺得放鴿子很殘忍 *(現有)*
- **秘密（別人）**：搭鴿籠時聽工人抱怨舞台左後方的支架會晃 *(新：二手傳聞，不是親眼證實)*
- **偏誤**：凡事往最壞處想
- **傳話**：跟動物有關的一定加一句「好可憐」；心事先跟小雯說
- **底線**：不讓鴿子在危險的地方被放飛
- **價碼**：如果鴿子可能受傷，她會說出收錢和支架的事
- **台詞**：「這樣會不會太可憐了……」「我、我只是擔心而已。」

### 小雯（記者）
- **擁有**：鎮上唯一的新聞部落格、相機裡的照片
- **專屬**：一篇文章全鎮都看得到；能翻公開帳目
- **今晚想要**：在慶典前拿到一則能救部落格的獨家
- **怕**：被證明寫了假新聞
- **秘密（自己）**：部落格快撐不下去 *(現有)*
- **秘密（別人）**：上週拍到市長和志明在鎮公所後門吵架 *(新事實)*
- **偏誤**：越否認越可疑
- **傳話**：標題一定聳動；只說「消息人士」
- **底線**：沒有任何來源，就不發文
- **價碼**：給她更大的獨家，她就先壓下另一則
- **台詞**：「這可是獨家喔。」「你確定？我可要寫了。」

### 美咲（咖啡廳）
- **擁有**：咖啡廳（全鎮的客廳）、女兒今晚登台
- **專屬**：店是全鎮的客廳，熟客最多（電話聯絡人 4 位，和美玲、小雯一樣）；能讓女兒不上台（扣住表演者）
- **今晚想要**：女兒順利演出
- **怕**：女兒在台上出事
- **秘密（自己）**：女兒其實怯場想退出，她還沒告訴志明 *(新事實)*
- **秘密（別人）**：老周常在店裡抱怨今晚的警力只有一半 *(連到老周的秘密)*
- **偏誤**：只要扯到孩子就全信
- **傳話**：先跟熟客聊，再打給老周；講得很溫情
- **底線**：不讓女兒上不安全的舞台
- **價碼**：為了女兒，她會說出老周的秘密
- **台詞**：「先喝杯咖啡，慢慢說。」「我女兒今晚要上台耶！」

### 老周（警長）
- **擁有**：今晚全部的警力（只有一半）、舞台封鎖權
- **專屬**：派警力、封鎖舞台、當場檢查
- **今晚想要**：平安無事，不被市長怪罪
- **怕**：人潮失控而警力不夠
- **秘密（自己）**：警力只有一半 *(現有)*
- **秘密（別人）**：去年志明的活動也偷工減料，是他壓下來的 *(新事實)*
- **偏誤**：寧可信其有
- **傳話**：只跟信任的人講，而且打官腔
- **底線**：沒親眼看過現場，不派警力
- **價碼**：市長要他壓下來，他會先壓；但只要孩子可能受傷，就不聽市長的
- **台詞**：「我得親眼看過才算數。」「這事我會處理，你先別張揚。」

### 林市長
- **擁有**：燈籠節的取消權、公所帳本
- **專屬**：公開聲明、取消燈籠節
- **今晚想要**：開場致詞順利、為連任加分
- **怕**：在全鎮面前丟臉
- **秘密（自己）**：預算超支三成，漲攤位費是為了補洞 *(現有)*
- **秘密（別人）**：美玲收的佈置費是公所撥的 *(連到美玲的秘密)*
- **偏誤**：越多人說，他越想否認
- **傳話**：壞消息從不親口說，都叫志明去說
- **底線**：絕不親口承認超支
- **價碼**：如果記者拿到帳本，他會把責任推給志明
- **台詞**：「各位鄉親，這完全是誤會。」「志明，這件事你去處理。」

### 志明（主辦人）
- **擁有**：舞台、節目表、所有工人
- **專屬**：貼公告、封鎖舞台、調整節目
- **今晚想要**：辦得風光，被市長誇獎
- **怕**：被追究責任
- **秘密（自己）**：舞台沒做結構檢查，支架鬆了 *(現有)*
- **秘密（別人）**：攤位費漲價是為了補市長的洞 *(現有，他本來就知道)*
- **偏誤**：出了事先想是誰害他
- **傳話**：壞消息一律說成「小問題」
- **底線**：八點前絕不取消節目
- **價碼**：如果市長要犧牲他，他就說出攤位費的真相
- **台詞**：「沒事沒事，小問題！」「八點準時開始，誰都不准拖！」

### 阿珠（章魚燒攤）
- **擁有**：攤商們的支持（一聲號召）、廣場最好的攤位
- **專屬**：號召攤商聚集；能讓攤商罷市
- **今晚想要**：攤位費降回來
- **怕**：今晚生意泡湯
- **秘密（自己）**：有一半攤商其實還沒繳漲價後的攤位費 *(新事實，市長可以拿來反制)*
- **秘密（別人）**：知道小雯的部落格快倒了 *(連到小雯的秘密)*
- **偏誤**：任何事都跟錢有關
- **傳話**：大聲講、拉群眾
- **底線**：慶典當晚不收攤，除非全體攤商一起
- **價碼**：只要攤位費降回來，她什麼都不追究
- **台詞**：「攤位費漲一倍，你說合理嗎！」「大家一起來！」

**秘密網**：每個人都握著另一個人的把柄。

- 阿德→市長（欠款）
- 美玲→志明（支架傳聞）
- 小雯→市長與志明（吵架照片）
- 美咲→老周（警力）
- 老周→志明（去年的事）
- 市長→美玲（佈置費）
- 阿珠→小雯（部落格）

任何一句話都可能同時碰到兩三條線，這正是你說的「三角戀、債務、恩情、背叛、收買」。

## 4. 人際關係 v2：有類型、有數值、有過去

現有關係只有 `trust / phone / 一句描述`。擴充成：

```ts
interface Relation {
  type: "前任" | "暗戀" | "債主" | "欠債" | "恩師" | "老搭檔" | "表面盟友" | "情報來源" | "鄰居" | "對頭" | ...;
  trust: number;      // 0..1 相信他說的話（現有）
  affection: number;  // 0..1 好感：會不會替他掩護
  fear: number;       // 0..1 恐懼：會不會照他說的做
  debt: number;       // -1..1 誰欠誰（正 = 對方欠我）
  past: string;       // 一句過去
  phone: boolean;
}
```

建議的關鍵關係（從你的投影片改寫，換成現有 8 人）：

| 關係 | 類型 | 過去 |
|---|---|---|
| 阿德 ↔ 美玲 | 前任，互相埋怨 | 她十年前退婚，他還放不下（**取代**現在的「天天聊天」） |
| 志明 → 美玲 | 暗戀、生意夥伴 | 鴿籠和花飾的訂單都是他給的 |
| 市長 → 阿德 | 欠債 | 去年點心錢還沒付 |
| 老周 ↔ 市長 | 老搭檔，但他知道太多 | 去年幫市長和志明壓過一件事 |
| 志明 ↔ 市長 | 表面盟友 | 不滿市長每年搶功 |
| 小雯 ↔ 阿德 | 情報來源 | 麵包店是她的消息站 |
| 美咲 ↔ 老周 | 老朋友 | 老周每天在店裡喝咖啡、發牢騷 |
| 阿珠 ↔ 市長 | 對頭 | 為攤位費吵過一架 |

**門檻解鎖動詞**（Gemma 只會看到它「可以」，但不一定要做）：

- 好感 ≥ 0.7：可以**替他掩護**（對別人說「他不會做那種事」）。
- 恐懼 ≥ 0.6：會**照他說的做**（市長叫老周先壓下來）。
- 對方欠我 ≥ 0.5：可以**當面討債**（阿德找市長要錢）。
- 信任 < 0.2：他說什麼都**先打折**（現在已經有）。

**平衡規則**（你投影片的「敵人的朋友也會被牽連」）：A 公開攻擊 B（爆料、當眾指責）時，B 的好友對 A 的信任 −0.15。這由引擎根據已驗證事件計算。

## 5. 不直接擺出來：玩家怎麼慢慢懂（核心）

你說得對，攤開所有數值會變成試算表遊戲。建議用**四種暗示**，從無形到有形：

1. **日常小戲（已上線一部分）**：
   - 阿德試吃時偷看烤箱（暗示他的秘密）。
   - 志明的舞台支架晃一下。
   - 阿珠對鎮公所比手畫腳。

   之後可以加：
   - 阿德看到美玲時突然轉身（前任）。
   - 市長經過麵包店時加快腳步（欠款）。
   - 美咲的女兒在咖啡廳門口緊張地練台詞（怯場）。
   - 老周在咖啡廳跟美咲抱怨（警力）。

   這些都是默劇或日常台詞，不說破，**看得懂的人會想到可以利用**。
2. **台詞（角色卡最後一欄）**：每個人的口頭禪會在故事中出現，玩家聽久了就認得出「這是阿德的語氣」。
3. **結算時揭露一項**：每局結束時，小報角落揭露一項**這局真的被觸發**的設定。例如「🔓 你發現了：阿德的傳話習慣——數字一定加倍」。只揭露 log 裡有證據的那一項。
4. **鎮民筆記（多局累積）**：每個角色一頁，欄位一開始是「？？？」，被觸發過的才會解開。玩過三、四局後，玩家會開始**故意**去推這些槓桿：「我知道阿德被市長羞辱就會爆料欠款，那我先讓市長取笑阿德……」

**怎麼誠實地判斷「被觸發了」**：在 Gemma 的回答格式加一個選填欄位 `motive`，讓它從自己的角色卡挑一項當作這次行動的主要原因（想要、怕、偏誤、底線、價碼、傳話習慣）。這是**模型自己的認知**，就像它現在寫的 `thought` 一樣，引擎只負責記錄並在筆記裡解鎖。結算只揭露真的出現在 log 裡的 motive。

## 6. 實作順序與時間（距離交件約 30 小時，扣掉影片與交件）

| 階段 | 內容 | 改動位置 | 估時 | 風險 |
|---|---|---|---|---|
| **A** | 角色卡 v2 進提示詞（只給本人看）+ 新秘密進 FACTS（含洩漏關鍵字）+ 關係加 type/past | scenario.ts、mind.ts、types.ts | 3 小時 | 提示詞變長約 +200 tokens，首次反應可能慢 0.5–1 秒 |
| **B** | `motive` 欄位 + 結算揭露一項 + 鎮民筆記（localStorage） | mind.ts、validate.ts、story.ts、UI | 3 小時 | 低 |
| **C** | 慶典八量表 + 20:00 結局規則 + 小報結局段落 | engine.ts（純規則）、story.ts | 3 小時 | 要調門檻，避免每局都「停辦」 |
| **D** | 門檻解鎖動詞（討債、掩護）+ 平衡規則 | engine.ts、validate.ts | 3 小時 | 新動詞會改變結局分佈，需要一批試玩 |
| **E** | 新的日常小戲暗示（前任、欠款、怯場） | vignettes.ts | 2 小時 | 低 |
